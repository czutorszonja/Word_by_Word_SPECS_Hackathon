# Hungarian audio recording list — Word by Word café demo

> **Backup plan.** The build first uses a generated Hungarian voice for all of these clips. Listen to them in the preview; record your own version only for clips that sound wrong (or all of them, if you prefer), using the same file name.

## Where to save
Save every clip in this folder inside the project:

```
Word_by_Word_SPECS_Hackhaton/Assets/Audio/hu/
```

(Create the `Audio` and `hu` folders if they don't exist yet.)

Use the **exact file name** from the tables below. The Lens is built with placeholder sounds under these same names, so when your file lands with the right name, it replaces the placeholder automatically — no rebuild needed. If Lens Studio is open, it picks up new files in `Assets/` by itself.

## Recording tips
- Format: `.wav` (`.mp3` also works — then keep the same name, just change the ending, and tell CLAD).
- Mono, 44.1 kHz or 48 kHz is fine. Most phone voice-recorder apps work; convert to wav if needed.
- One word or phrase per file. Leave about half a second of silence at the start and end, no longer.
- Quiet room, phone about a hand's width from your mouth, natural speed — the way you'd say it to a learner.
- File names have no accents or spaces on purpose. Keep them exactly as written.
